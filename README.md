# Лабораторная работа 1. Растеризация отрезков и заливка фигур

Консольная программа на C++ рисует отрезки и выпуклые многоугольники из 3–8 вершин на сетке 40 × 20. Она показывает результат в терминале и сохраняет его в файлы BMP.

Программа заливает только выпуклые многоугольники. Перед заливкой она проверяет вершины и просит ввести их заново, если контур не прошёл проверку.

## Цель

Научиться рисовать отрезки на сетке из пикселей, заливать фигуры двумя способами и сравнивать результаты.

## Методы

- **Брезенхэм и DDA.** Программа строит один отрезок двумя способами и считает, в скольких клетках рисунки отличаются. Брезенхэм выбирает следующий пиксель с помощью целых чисел. DDA вычисляет промежуточные точки и округляет их координаты.
- **Flood fill.** Заливка начинается с точки внутри фигуры и переходит в соседние свободные клетки. Можно выбрать 4 соседей по сторонам или 8 с учётом диагоналей. При заливке многоугольника диагональный проход между двумя клетками границы закрыт.
- **Scanline.** Программа для каждой строки находит пересечения с рёбрами и закрашивает свободные клетки между ними.

## Запуск

Собери и запусти программу в PowerShell из папки с исходником.

```powershell
g++ -std=c++17 .\lab1_full.cpp -o .\lab1_full.exe
.\lab1_full.exe
```

Если исходник называется `geometry_lab.cpp`, укажи это имя в первой команде. Пункт `0` завершает программу.

## Примеры работы

### 1. Сравнение Брезенхэма и DDA

Выбираем пункт `1` и вводим концы отрезка `(6, 4)` и `(0, 1)`.

```text
1
6 4
0 1
```

Оба алгоритма рисуют по 7 пикселей. Когда отрезок проходит ровно между двумя пикселями, алгоритмы могут выбрать разные клетки. В этом примере сетки отличаются в 6 клетках.

### 3. Заливка контура с диагональными ступеньками

Выбираем пункт `3`. Программа рисует готовый ромб и показывает заливки с 4 и 8 соседями.

### Сохранение в BMP*

Программа автоматически сохраняет рисунки в файлы `.bmp` в папке, из которой её запустили. Каждая клетка сетки занимает блок 12 × 12 пикселей, поэтому размер картинки получается 480 × 240 пикселей.

Функция `saveBmp` сначала записывает заголовок BMP с размерами изображения и указанием, где начинаются пиксели. Затем она подбирает цвет по символу клетки сетки, например `.` становится белым фоном, а `*` обозначает заливку. Пиксели записываются по строкам снизу вверх, по три байта на цвет в порядке синий, зелёный, красный (BGR).

Имя файла появляется в терминале после `Saved:`. Например, `polygon_scanline.bmp` содержит результат построчной заливки. BMP можно открыть в Paint и сделать скриншот для README.
